검증할 대상: $ARGUMENTS

1. `AGENTS.md`, `docs/대화_AI_개발가이드.md`, 관련 현재 코드·실측을 먼저 읽는다.
2. 사용자가 이 명령을 요청했고 읽기 전용 보조 도구를 사용할 수 있으면 독립 검증을 요청한다.
   자료에는 증상·재현 조건·관측값을 넣고 메인의 원인 결론은 먼저 알려주지 않는다.
   보조 도구가 없으면 메인이 증거를 대조하고 독립 검증 미실행을 명시한다.
3. 도구에 파일 접근 기능이 있으면 관련 경로를 제공한다. 접근할 수 없는 경우 필요한 코드·문서 발췌를 제공한다.
   실제 키·토큰·참여자 자료는 포함하지 않는다. 과거 PC의 읽기/쓰기 제한을 현재 환경에 가정하지 않는다.
4. 메인의 진단과 검증 결과가 갈리면 재현 가능한 검사로 가른다. 코드 수정·배포·유료 생성은 이 명령의 범위가 아니다.

출력은 `확인한 사실 / 원인 후보와 근거 / 미확정 사항 / 다음 검증` 순서로 작성한다.
현재 동작의 기준은 서버 구조·AI 테스트 문서다. 과거 Raon 실험은 관련 가설이 있을 때만 대조한다.
결과 파일이 필요하면 `tools/_work/reviews/`에 실행별 새 파일로 남긴다.
