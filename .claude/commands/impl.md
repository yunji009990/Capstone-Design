할 일: $ARGUMENTS

`AGENTS.md`와 `docs/대화_AI_개발가이드.md`를 읽고 현재 Git 변경을 구분한다.
기본 대상은 대화 서버·대화 테스트·평가 도구다. T포즈·3D 제작은 팀원 범위다.
공통 경계 변경은 요청에 필요한 범위만 포함하고 제공자·소비자 검사를 함께 실행한다.

사용자가 이 명령으로 보조 구현안을 요청했고 도구를 사용할 수 있으면 읽기 전용으로 맡긴다.
자료에는 목표, 현재 코드, 기대 동작, 검증 조건을 넣는다. 편집안은 파일·수정 근거·원문/대체문 또는 검증 가능한 patch로 받는다.
현재 도구가 읽을 수 없으면 필요한 발췌를 제공한다. 권한·모델을 임의 변경하거나 예전 PC 설정을 강제하지 않는다.
보조 도구가 없으면 메인이 같은 절차로 구현하며, 보조 검토를 받았다고 보고하지 않는다.

적용은 메인이 한다. `Assets/`와 문서는 보조 편집 대상에서 제외하고, 필요한 Unity 변경은 메인이 별도로 검증한다.
수정안의 원문과 현재 파일을 대조하고 다른 작업자의 변경을 보존한다. 실패를 이유로 전체 파일을 자동 복원하지 않는다.
적용 후 `python tools/check.py --area dialogue`를 실행하고 결과 파일과 제한을 보고한다.
공통 경계를 수정했으면 `--area all`도 확인한다. 서버 배포는 현재 요청의 범위에 따라 진행한다.
대화 서버 경로는 `~/capstone-server`, 웹·등록·Tripo는 `~/webapp`이다.
