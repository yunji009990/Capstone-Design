# 다시, 봄

**2026-10-08 서버 재개:** 10월 3일 보관한 설정으로 서비스 6개를 다시 실행했다.
서버·외부 PC의 준비 상태와 Scene_2 Play의 인물 조회·모델 로딩·시작 버튼 활성화를 확인했다.
사용·종료·재시작은 [프로젝트 보관과 재시작](docs/프로젝트_보관_재시작_20261003.md)을 따른다.
`hj`·`jw` 비교와 `main` 반영 근거는 [브랜치 최종 정리](docs/브랜치_최종정리_20261003.md)에 있다.

Unity의 VR 카페에서 등록한 인물과 음성으로 대화하는 캡스톤.
현재 입력은 **Whisper large-v3 → 판정기·LLM → VoxCPM2 TTS → Unity 음성·자막**으로 동작한다.
대화·모델 제작 코드 대조는 **2026-10-01**, Scene_2 그래픽은 **2026-10-09 `main`** 기준이다.
최종 설정·검증 범위는 [현재 구현 현황](docs/현재_구현_현황.md)을 따른다.
전체 기술 흐름과 구현 범위는 [프로젝트 기술 개요](docs/프로젝트_기술_개요.md)에 정리했다. 서버 확인 날짜는 코드 기준일과 구분한다.
TTS 전환·참조 음성 기준은 [TTS 인계 문서](docs/TTS_작업인계_20260918.md)에 있다.
연결별 핵심 기억, TTS 생성 중 오디오 전송, 캐릭터별 추론 대기 리액션을 서버에 적용했다.
등록 웹은 설문을 바꾸면 인물 설정을 다시 작성하고, 기본 예시 없이 확인한 인물만 등록한다.
세션 ID는 서버가 자동 발급한다. 관계·호칭·말투는 설문 v2 변환 규칙을 따른다.
사진을 포함해 등록하면 **머리 생성 → 리깅된 고정 몸체 결합** 작업을 접수한다.
9월 30일 웹에서 시작한 새 등록의 모델 완료·등록 API 전달을 확인했다. 해당 결과의 외관 품질·VR 체험은 별도다.
현재 작업자는 머리 생성 경로만 사용하며 몸체·Blender가 없으면 실패한다. 완성 GLB에는 리그를 보존하고,
동작은 Unity에서 Mixamo 클립으로 적용한다. 일시적인 Tripo 조회·다운로드 오류는 작업 ID를 유지하며 재시도한다.

현재 우리 담당은 **대화 AI**, T포즈·3D 제작은 팀원 담당이다.
10월 7~9일에는 사용자 요청으로 전국 대회 시연 영상에 필요한 Scene_2 배경·창 유리·원경 수목도 개선했다.
완성 목표는 **10월 27일**이다. 창밖 근경은 3D 정원이고, 먼 수목은 전체 나무가 담긴 투명 PNG다.
10월 9일 사용자가 조절을 마친 두 창의 반사 설정과 테이블·담장 배치를 보존한다.
`Tools > 다시봄 > 그래픽 > 유리 반사 조절 열기`에서 창별 슬라이더·숫자를 바꾸고 `반사 설정 저장`을 누른다.
각 설정의 의미와 저장된 최종값은 [현재 그래픽 현황](docs/현재_구현_현황.md#scene_2-그래픽-현재-설정)에 있다.
그래픽은 Editor 촬영까지 확인했으며 최종 HMD의 양안 표시·성능·시연 영상 확인은 남아 있다.
AI 작업은 [공통 지침](AGENTS.md) → [하네스 사용법](docs/AI_하네스.md) →
[대화 AI 개발 가이드](docs/대화_AI_개발가이드.md) 순서로 시작한다.
기본 모의 검사 명령은 `python tools/check.py --area dialogue`다.

Unity 2022.3.62f2. `Tools > Dialogue > Open AI test scene`을 열고 Play 후
참조 목소리를 선택하고 마이크로 질문한다. VoxCPM2가 참조 목소리를 조건으로 답변 음성을 생성하면서 전송한다.
답변 생성 중 끼어들면 잠시 멈추고, 발화 의도에 따라 이어 말하기·수정·주제 전환·대기를 선택한다.
추론 답변이 늦어지면 미리 준비한 짧은 리액션을 한 번 재생한다. 리액션과 본답변의 첫 음성 시간을 구분한다.
웹에서 등록한 인물로 체험할 때는 `Assets/Scenes/Scene_2.unity`를 직접 열고 Play 후 화면의 체험 시작을 누른다.
