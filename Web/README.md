# 다시, 봄 — 세션 등록 도구

영상이나 음성에서 **화자를 분리해 목소리를 고르고**, 인물 설정과 함께 Raon 서버에 등록한다.

임시 도구가 아니라 **제품 코드**다. 사용자 입력을 받는 화면은 따로 붙더라도,
화자 분리부터 세션 등록까지의 처리는 여기가 담당한다.

## 실행

```bash
cd Web && python -m uvicorn app:app --port 8500
```

브라우저에서 `http://localhost:8500`.

## 흐름

```
파일 업로드 → NeMo 화자 분리 → 화자 선택(들어보고) → 인물 설정 → 세션 등록
                                                              ↓
                                            Unity 가 5초 내 그 인물로 전환
```

## 참조 음성을 넘기는 두 가지 방법

**화자 분리** — 영상·음성을 올리면 사람별로 나눠주고, 고른 사람의 참조를 자동으로 만든다.
그 참조는 **여러 조각을 이어붙인 것**이다. 음색만 쓰는 `tts()` 에는 문제가 없지만,
억양까지 잇는 `tts_continuation`(`RAON_CONT=1`) 에는 맞지 않는다.

**직접 지정** — 준비한 오디오를 그대로 참조로 쓴다. 24kHz 모노 변환만 하고
자르거나 이어붙이지 않는다. 등록 후 `/last_ref.wav` 로 **서버에 넘어간 것과 같은 바이트**를
되들려주므로, 보낸 것과 쓰이는 것이 다를 여지가 없다.

억양을 복제하려면 **한 사람이 10~30초 자연스럽게 말하는 음성**이어야 한다.
참조에 없는 말투는 나오지 않는다 — 낭독조를 넣으면 낭독조가 나온다.

## 화자 분리는 새로 만들지 않았다

`Desktop/capstone/voice_clone_studio` 의 **NeMo MSDD 엔진을 그대로 호출**한다.
가정용 영상은 여러 사람이 섞여 있어서 단순히 "소리 큰 구간"을 자르면 참조 음성이
망가진다. 그쪽이 이미 해결해둔 문제라 재사용하는 게 맞다.

경로는 환경변수로 바꿀 수 있다.

```bash
set VCS_DIR=C:\...\voice_clone_studio
```

**CPU 전용이라 느리다.** 이 PC 의 torch 는 `2.13.0+cpu` 라 긴 영상은 몇 분 걸린다.
그래서 추출은 백그라운드 작업 + 폴링 구조로 만들었다.

## 화면에서 보는 것

- **파형** — 화자별로 색이 다르다. 화자를 고르면 그 사람 구간만 진하게 표시된다.
  아래쪽 빨간 띠는 두 사람이 겹쳐 말한 구간이다.
- **화자 카드** — 참조 길이와 SNR. 참조는 **10~30초 · SNR 15dB 이상**이 좋고,
  벗어나면 색으로 표시된다. **반드시 들어보고 고를 것** — 복제 품질이 여기서 결정된다.

## 인물 설정에서 중요한 것

**대화 예시가 결정적이다.** 실험으로 확인했다.

| | 규칙만 (120자) | 예시 포함 (722자) |
|---|---|---|
| "반말로 말하세요" 준수 | ✗ 존댓말로 답함 | ✓ |
| 캐릭터 | 불특정 인물 | 지정한 인물 |

"존댓말을 쓰지 마세요"라고 명시해도 지켜지지 않는데, 대화 예시 네 줄을 넣으면 바로 잡힌다.
서버가 공통 규칙(이모지 금지, 길이 등)은 자동으로 앞에 붙이므로,
여기에는 **그 사람이 누구이고 어떻게 말하는지**만 쓰면 된다.

## 설정

| 환경변수 | 기본값 |
|---|---|
| `RAON_URL` | `http://220.69.208.201:8000` |
| `RAON_TOKEN` | 서버 `start.sh` 의 값과 같아야 함 |
| `VCS_DIR` | `C:\Users\user\Desktop\capstone\voice_clone_studio` |

`workspace/` 는 업로드·추출 결과가 쌓이는 곳이라 버전 관리하지 않는다. 비워도 된다.

## 환경변수

```
SURVEY_ACCESS_CODE   비우면 접근 코드 게이트 없음 (교내망 전용일 때)
ADMIN_PASSWORD       관리자 페이지 비밀번호 (기본 dasibom-admin — 공개 전 반드시 바꿀 것)
TRIPO_API_KEY        3D 모델 생성. 없으면 stub 으로 건너뛴다 (대화는 정상)
RAON_URL / RAON_TOKEN   Raon 서버
VCS_DIR              화자 분리 엔진(voice_clone_studio) 경로
```
