# 다시, 봄 — 세션 등록 도구

영상이나 음성에서 **화자를 분리해 목소리를 고르고**, 인물 설정과 함께 Raon 서버에 등록한다.

임시 도구가 아니라 **제품 코드**다. 사용자 입력을 받는 화면은 따로 붙더라도,
화자 분리부터 세션 등록까지의 처리는 여기가 담당한다.

## 실행

```bash
cd Web && python -m uvicorn app:app --port 8500
```

브라우저에서 `http://localhost:8500`.

## 흐름

목소리를 **맨 앞(2단계)** 에서 받는다. 다음을 누르는 것이 곧 분리 시작이고, 화면은
바로 3단계로 넘어간다. 답을 적는 동안 뒤에서 끝나므로 기다리는 시간이 없다.

```
1 동의 → 2 목소리 올림 ─┐
                        │ (뒤에서 화자 분리, 63~99초)
3 기본정보 · 4 추억 · 5 마음 · 6 대화 톤
                        │
7 화자 고르기 ←─────────┘   → 8 인물 확인 → 9 등록
                                              ↓
                                Unity 가 5초 내 그 인물로 전환
```

되짚어 와서 다음을 다시 눌러도 새로 돌리지 않는다. 파일이나 화자 수를 **바꿨을 때만**
초기화한다. 실패하면 7단계에 **다시 시도** 단추가 나온다.

## 참조 음성을 넘기는 두 가지 방법

화자 수 드롭다운이 갈라준다.

**자동 판별 · 2~5명** — 영상·음성을 사람별로 나눠주고, 고른 사람의 참조를 자동으로 만든다.
그 참조는 **여러 조각을 이어붙인 것**이다. 음색만 쓰는 `tts()` 에는 문제가 없지만,
억양까지 잇는 `tts_continuation`(`RAON_CONT=1`) 에는 맞지 않는다.

**한 명 (분리 안 함)** — 분리기를 건너뛰고 올린 파일을 그대로 참조로 쓴다. 24kHz 모노
변환만 한다. 등록 후 `/last_ref.wav` 로 **서버에 넘어간 것과 같은 바이트**를 되들려주므로,
보낸 것과 쓰이는 것이 다를 여지가 없다.

억양을 복제하려면 **한 사람이 10~30초 자연스럽게 말하는 음성**이어야 한다.
참조에 없는 말투는 나오지 않는다 — 낭독조를 넣으면 낭독조가 나온다.

## 화자 분리는 새로 만들지 않았다

`voice_clone_studio` 의 **NeMo MSDD 엔진을 그대로 가져왔다.** 가정용 영상은 여러
사람이 섞여 있어서 단순히 "소리 큰 구간"을 자르면 참조 음성이 망가진다. 그쪽이 이미
해결해둔 문제라 재사용하는 게 맞다.

코드는 **`extraction/` 에 저장소 안으로 들어와 있다.** 예전에는 바탕화면 경로를
`VCS_DIR` 로 가리켰는데 그 PC 에서만 돌았다. 무거운 `nemo_env`(1.8GB)만 저장소 밖이며,
만드는 법은 [`extraction/README.md`](extraction/README.md) 에 있다.

**CPU 전용이다.** 이 PC 의 torch 는 `2.13.0+cpu`. **실측 63~99초**(3~10MB, 6분 24초
오디오가 66초로 길이의 1/6쯤). 추출은 백그라운드 작업 + 폴링 구조라 설문을 채우는
동안 뒤에서 돈다. GPU 로 옮기면 이걸 아끼지만, 그 시간이 이미 설문에 가려져서
**지금은 CPU 로 둔다.**

## 화자 카드에서 보는 것

**반드시 들어보고 고를 것** — 복제 품질이 여기서 결정된다. 숫자는 둘만 본다.

| 배지 | 뜻 |
|---|---|
| **명료도** (1~4kHz 비율) | **25% 미만**이어야 한다. 넘으면 합성에 지지직거림이 낀다 |
| **쉼** | 20%를 넘으면 등록할 때 자동으로 줄인다. 안 줄이면 합성된 목소리도 중간에 멈춘다 |

예전에는 **SNR** 과 참조 길이를 기준으로 썼는데 **둘 다 지지직과 무관하다는 것이
실측으로 확인됐다** — 35dB 짜리가 통과하며 실패하고, 59dB 로 올려도 그대로였다.
파형 그림도 있었지만 고르는 근거가 못 돼서 없앴다. 자세한 것은
[`참조음성_실험결과.md`](../docs/참조음성_실험결과.md).

## 인물 설정에서 중요한 것

**대화 예시가 결정적이다.** 실험으로 확인했다.

| | 규칙만 (120자) | 예시 포함 (722자) |
|---|---|---|
| "반말로 말하세요" 준수 | ✗ 존댓말로 답함 | ✓ |
| 캐릭터 | 불특정 인물 | 지정한 인물 |

"존댓말을 쓰지 마세요"라고 명시해도 지켜지지 않는데, 대화 예시 네 줄을 넣으면 바로 잡힌다.
서버가 공통 규칙(이모지 금지, 길이 등)은 자동으로 앞에 붙이므로,
여기에는 **그 사람이 누구이고 어떻게 말하는지**만 쓰면 된다.

## 설정

| 환경변수 | 기본값 |
|---|---|
| `RAON_URL` | `http://220.69.208.201:8000` |
| `RAON_TOKEN` | 서버 `start.sh` 의 값과 같아야 함 |
| `NEMO_PY` | 비우면 `extraction/nemo_env/Scripts/python.exe` |

`workspace/` 는 업로드·추출 결과가 쌓이는 곳이라 버전 관리하지 않는다. 비워도 된다.

## 환경변수

```
SURVEY_ACCESS_CODE   비우면 접근 코드 게이트 없음 (교내망 전용일 때)
ADMIN_PASSWORD       관리자 페이지 비밀번호 (기본 dasibom-admin — 공개 전 반드시 바꿀 것)
TRIPO_API_KEY        3D 모델 생성. 없으면 stub 으로 건너뛴다 (대화는 정상)
RAON_URL / RAON_TOKEN   Raon 서버
NEMO_PY              nemo_env 의 python.exe. 비우면 extraction/nemo_env 를 쓴다
```

## 화면

| 주소 | 무엇 |
|---|---|
| `/` | 동의 → 목소리 → 설문 → 화자 고르기 → 인물 → 등록. 9단계 |
| `/after` | 체험 후 안내와 **본인 세션 코드로 자료 폐기** |
| `/admin` | 세션 목록·상세, 설문·사진·음성·모델 내려받기, 모델 재시도, 폐기·삭제 |

참여자 자료는 `Survey/data/` 에 쌓이고 저장소에 올라가지 않는다.
