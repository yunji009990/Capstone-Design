# 다시, 봄 — 세션 등록 도구

영상이나 음성에서 **화자를 분리해 목소리를 고르고**, 인물 설정과 함께 Raon 서버에 등록한다.

임시 도구가 아니라 **제품 코드**다. 사용자 입력을 받는 화면은 따로 붙더라도,
화자 분리부터 세션 등록까지의 처리는 여기가 담당한다.

## 실행 — **이 저장소가 아니라 서버에서 돈다** (2026-09-09 부터)

```bash
ssh raon "cd ~/webapp; ./web_start.sh"     # 켜기
ssh raon "cd ~/webapp; ./web_stop.sh"      # 끄기
ssh raon "tail -f ~/webapp/Web/web.log"    # 로그
```

브라우저에서 **`http://220.69.208.201:8500`**. 교내망이면 아무 기계에서나 된다.

**왜 옮겼나** — 각자 PC 에서 띄우던 때는 파이썬·의존성·`.env` 를 저마다 갖춰야
해서 새로 받은 사람이 거의 항상 막혔다. 유니티의 「서버 켜기」가 `python` 을 그냥
불렀는데 그 이름이 어느 파이썬을 가리킬지는 기계마다 다르다.

**옮길 수 있었던 이유는 이 웹이 마이크를 안 쓰기 때문이다.** 파일을 올리는
구조라 https 가 필요 없다. **브라우저 녹음을 넣으면 그때는 인증서가 필요하다** —
크롬은 localhost 아닌 http 에서 마이크를 막는다.

이 PC 에서 띄워 볼 수도 있다. 다만 `python` 이 아니라 의존성이 깔린 파이썬을
직접 가리켜야 한다.

```powershell
cd Web
C:\Users\user\AppData\Local\Programs\Python\Python310\python.exe -m uvicorn app:app --port 8500
```

### 서버 판에서 다른 것

| | |
|---|---|
| `RAON_URL` | `http://127.0.0.1:8000` — 같은 기계다 |
| 화자 분리 | **안 된다.** `nemo_env` 가 없다. 「한 명 (분리 안 함)」으로만 |
| `TRIPO_API_KEY` | 비어 있다. 유니티 창이나 `POST /admin/tripo` 로 넣는다 |
| 관리자 비번 | 기본값에서 바꿨다. 서버의 `~/webapp/Web/.env` 에 있다 |

### 3D 키를 넣고 지우는 법

관리자 비밀번호로 막혀 있고, **키는 되돌려주지 않는다**(앞 네 글자만 알려준다).
`from_secrets()` 가 부를 때마다 환경변수를 읽으므로 **재시작이 필요 없다.**

```bash
curl -H "X-Admin-Pw: <비번>" -F "key=tsk_..." http://220.69.208.201:8500/admin/tripo
curl -H "X-Admin-Pw: <비번>" -F "key="        http://220.69.208.201:8500/admin/tripo   # 지우기
```

유니티에서는 `Tools > 서버 연결 상태 확인` 창에 칸이 있다.

**공용 기계다**(`uc` 사용자와 함께 쓴다). 전용 키를 새로 발급하고, 지출 상한을
걸고, **시연이 끝나면 지운다.**

콘솔에는 **폴링이 안 보인다.** 웹 화면과 Unity 창이 저마다 5초마다 `/status` 를 두드리고
추출 중에는 `/extract/{job}` 이 1.2초마다 붙어서, 그대로 두면 분당 100줄이 넘게 흘러
정작 봐야 할 `[모델]`·`[설문저장 실패]` 가 밀려 사라진다. **잘 돌아간 것만** 가리므로
200 이 아닌 폴링은 그대로 올라온다.

## 흐름

**올릴 파일 둘을 앞에서 몰아 받는다.** 목소리(2단계) 다음이 곧 사진(3단계)이라
자료를 두 번 찾을 일이 없다. 목소리에서 다음을 누르는 것이 분리 시작이고, 화면은
바로 넘어간다. 나머지를 적는 동안 뒤에서 끝나므로 기다리는 시간이 없다.

```
1 동의 → 2 목소리 올림 ─┐
             3 사진     │ (뒤에서 화자 분리, 63~99초)
4 기본정보 · 5 추억 · 6 마음 · 7 대화 톤
                        │
8 화자 고르기 ←─────────┘   → 9 인물 확인 → 10 등록
                                              ↓
                                Unity 가 5초 내 그 인물로 전환
```

**사진은 없어도 넘어간다** — 3D 모델만 안 생기고 대화는 정상이다.

되짚어 와서 다음을 다시 눌러도 새로 돌리지 않는다. 파일이나 화자 수를 **바꿨을 때만**
초기화한다. 실패하면 8단계에 **다시 시도** 단추가 나온다.

## 참조 음성을 넘기는 두 가지 방법

화자 수 드롭다운이 갈라준다.

**자동 판별 · 2~5명** — 영상·음성을 사람별로 나눠주고, 고른 사람의 참조를 자동으로 만든다.
그 참조는 **여러 조각을 이어붙인 것**이다. 음색만 쓰는 `tts()` 에는 문제가 없지만,
억양까지 잇는 `tts_continuation`(`RAON_CONT=1`) 에는 맞지 않는다.

**한 명 (분리 안 함)** — 분리기를 건너뛰고 올린 파일을 그대로 참조로 쓴다. 24kHz 모노
변환만 한다. 등록 후 `/last_ref.wav` 로 **서버에 넘어간 것과 같은 바이트**를 되들려주므로,
보낸 것과 쓰이는 것이 다를 여지가 없다.

억양을 복제하려면 **한 사람이 10~30초 자연스럽게 말하는 음성**이어야 한다.
참조에 없는 말투는 나오지 않는다 — 낭독조를 넣으면 낭독조가 나온다.

## 화자 분리는 새로 만들지 않았다

`voice_clone_studio` 의 **NeMo MSDD 엔진을 그대로 가져왔다.** 가정용 영상은 여러
사람이 섞여 있어서 단순히 "소리 큰 구간"을 자르면 참조 음성이 망가진다. 그쪽이 이미
해결해둔 문제라 재사용하는 게 맞다.

코드는 **`extraction/` 에 저장소 안으로 들어와 있다.** 예전에는 바탕화면 경로를
`VCS_DIR` 로 가리켰는데 그 PC 에서만 돌았다. 무거운 `nemo_env`(1.8GB)만 저장소 밖이며,
만드는 법은 [`extraction/README.md`](extraction/README.md) 에 있다.

**CPU 전용이다.** 이 PC 의 torch 는 `2.13.0+cpu`. **실측 63~99초**(3~10MB, 6분 24초
오디오가 66초로 길이의 1/6쯤). 추출은 백그라운드 작업 + 폴링 구조라 설문을 채우는
동안 뒤에서 돈다. GPU 로 옮기면 이걸 아끼지만, 그 시간이 이미 설문에 가려져서
**지금은 CPU 로 둔다.**

## 화자 카드에서 보는 것

**반드시 들어보고 고를 것** — 복제 품질이 여기서 결정된다. 숫자는 둘만 본다.

| 배지 | 뜻 |
|---|---|
| **명료도** (1~4kHz 비율) | **25% 미만**이어야 한다. 넘으면 합성에 지지직거림이 낀다 |
| **쉼** | 20%를 넘으면 등록할 때 자동으로 줄인다. 안 줄이면 합성된 목소리도 중간에 멈춘다 |

예전에는 **SNR** 과 참조 길이를 기준으로 썼는데 **둘 다 지지직과 무관하다는 것이
실측으로 확인됐다** — 35dB 짜리가 통과하며 실패하고, 59dB 로 올려도 그대로였다.
파형 그림도 있었지만 고르는 근거가 못 돼서 없앴다. 자세한 것은
[`참조음성_실험결과.md`](../docs/참조음성_실험결과.md).

## 인물 설정에서 중요한 것

**대화 예시가 결정적이다.** 실험으로 확인했다.

| | 규칙만 (120자) | 예시 포함 (722자) |
|---|---|---|
| "반말로 말하세요" 준수 | ✗ 존댓말로 답함 | ✓ |
| 캐릭터 | 불특정 인물 | 지정한 인물 |

"존댓말을 쓰지 마세요"라고 명시해도 지켜지지 않는데, 대화 예시 네 줄을 넣으면 바로 잡힌다.
서버가 공통 규칙(이모지 금지, 길이 등)은 자동으로 앞에 붙이므로,
여기에는 **그 사람이 누구이고 어떻게 말하는지**만 쓰면 된다.

## 설정

| 환경변수 | 기본값 |
|---|---|
| `RAON_URL` | `http://220.69.208.201:8000` |
| `RAON_TOKEN` | 서버 `start.sh` 의 값과 같아야 함 |
| `NEMO_PY` | 비우면 `extraction/nemo_env/Scripts/python.exe` |
| `RAON_BOOTSTRAP` | `1`. 등록 뒤 **1세대 참조**를 자동으로 만들어 바꿔 단다 |

**`RAON_BOOTSTRAP` 은 등록 시간을 32초 → 77초로 늘린다.** 그 대가로 첫낱말이 새는
비율이 잡힌다(소리 온도 1.6 에서 19/45 → 3/45). `0` 이면 원본 참조를 그대로 쓴다.
근거는 [`음성대화_작업현황.md`](../docs/음성대화_작업현황.md) 3순위의 네 칸 표.

`workspace/` 는 업로드·추출 결과가 쌓이는 곳이라 버전 관리하지 않는다. 비워도 된다.

## 환경변수 — `.env` 에 넣는다

키를 저장소에 넣지 않으면서 PC 마다 다르게 두려고 `Web/.env` 를 읽는다. 이 파일은
`.gitignore` 로 빠지고, `.env.example` 이 서식을 보여준다.

```bash
cd Web
copy .env.example .env      # 그리고 값을 채운다
```

서버가 뜰 때 한 번 읽으므로 **고친 뒤에는 껐다 켜야 한다.** 이미 설정된 환경변수가
있으면 그쪽이 이긴다 — 한 번만 다른 값으로 띄워보고 싶을 때를 위해서다.

```
TRIPO_API_KEY        3D 모델 생성. 없으면 stub 으로 건너뛴다 (대화는 정상)
ADMIN_PASSWORD       관리자 페이지 비밀번호 (기본 dasibom-admin — 공개 전 반드시 바꿀 것)
SURVEY_ACCESS_CODE   비우면 접근 코드 게이트 없음 (교내망 전용일 때)
RAON_URL / RAON_TOKEN   Raon 서버
RAON_BOOTSTRAP       1세대 참조 자동 생성. 비우지 말 것 (아래 주의)
NEMO_PY              nemo_env 의 python.exe. 비우면 extraction/nemo_env 를 쓴다
```

### 주의 — `.env` 에서 `키=` 는 「기본값 사용」이 아니다

`_load_env()` 가 `os.environ.setdefault(k, v)` 로 올리기 때문에, `RAON_TOKEN=` 처럼
**값 없이 이름만 적으면 환경변수가 빈 문자열로 설정된다.** 그러면 `os.environ.get(k, 기본값)`
이 기본값이 아니라 빈 문자열을 돌려준다. 실제 결과는 이렇다.

| 빈 값으로 두면 | 무슨 일이 나는가 |
|---|---|
| `RAON_TOKEN=` | `X-Token` 헤더를 아예 안 보내서 Raon 서버가 **전부 401** |
| `ADMIN_PASSWORD=` | 비밀번호가 빈 문자열이 되어 **아무 것도 안 친 사람이 `/admin` 에 들어온다** |
| `RAON_BOOTSTRAP=` | `"" != "1"` 이라 **1세대 참조가 조용히 꺼진다** |

**기본값을 쓰고 싶으면 줄 전체를 `#` 으로 주석 처리하거나 지운다.**

키가 잡혔는지는 `GET /status` 의 `tripo` 로 확인한다(값은 안 내보낸다). Unity 의
**Tools > 서버 연결 상태 확인** 창에도 같은 것이 나온다.

## 화면

| 주소 | 무엇 |
|---|---|
| `/` | 동의 → 목소리 → 사진 → 설문 → 화자 고르기 → 인물 → 등록. 10단계 |
| `/after` | 체험 후 안내와 **본인 세션 코드로 자료 폐기** |
| `/admin` | 세션 목록·상세, 설문·사진·음성·모델 내려받기, 모델 재시도, 폐기·삭제 |

참여자 자료는 `Survey/data/` 에 쌓이고 저장소에 올라가지 않는다.
