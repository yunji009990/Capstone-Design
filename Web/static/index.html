다시, 봄 — 세션 등록

영상이나 음성에서 화자를 분리해 목소리를 고르고, 인물 설정과 함께 Raon 서버에 등록합니다.
상태 확인 중…

1. 참조 음성

오디오·영상을 끌어다 놓거나 클릭해서 선택 (mp3, wav, m4a, mp4, mov …)
0이면 자동 판별
참조로 쓸 오디오를 끌어다 놓거나 클릭해서 선택
화자 분리를 건너뛰고 이 파일을 참조로 씁니다. 24kHz 모노로 맞추고 음량을 정규화하며, 쉬는 구간이 20%를 넘으면 줄여서 이어붙입니다(그대로 두면 합성된 목소리도 중간에 멈춥니다). 한 사람이 10~30초 끊지 말고 이어서 말하는 음성이어야 하고, 원하는 말투가 이 음성 안에 있어야 합니다 — 참조에 없는 억양은 복제되지 않습니다.

2. 화자 선택

색이 화자입니다. 아래에서 사용할 목소리를 고르고 반드시 들어보세요 — 복제 품질이 여기서 결정됩니다.
명료도는 25% 미만이어야 합니다. 높으면 합성 결과에 지지직거리는 소리가 낍니다 (방송·영상용으로 후처리된 소리가 그렇습니다). 쉼이 20%를 넘으면 등록할 때 자동으로 줄입니다.

3. 인물 설정

등록하면 서버의 이전 인물은 삭제됩니다. 서버는 한 번에 한 사람만 보관합니다.
대화 예시가 결정적입니다. 규칙만 적으면 모델이 무시하고 존댓말 쓰는 일반 비서처럼 답합니다. 그 사람이 할 법한 말 3~5쌍을 반드시 넣으세요.
서버가 [사전지식] 항목으로 붙여줍니다. 위 예시는 그대로 두지 말고 실제 인물의 것으로 바꾸세요. 구체적인 장면 한 줄이 성격 설명 열 줄보다 낫습니다.

4. 등록

참조 음성이 선택되지 않았습니다.
