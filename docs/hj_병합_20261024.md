준비 UI는 기존 서버 확인 버튼 하나를 준비 재확인으로 재사용한다. hj의 테마는 색·스프라이트를 바꾸며 현재 준비 안내·마이크 선택·시작/종료 연결을 유지한다.
추가 준비 버튼이나 별도 확인 단계를 만들지 않는다. 종료는 기존 입력·음성 중지 → 0.8초 페이드 → 인물 숨김이다.

`PlayerArrival`은 카메라 이동·발소리 초안으로만 보존한다. 씬에 연결하거나 VR 카메라 자동 이동을 켜지 않는다.
삭제한 Chibi 예제 모델·프리팹·재질에 대한 남은 씬/프리팹의 직접 GUID 참조는 발견되지 않았다.

## 사용 방법

1. `Assets/Scenes/StartScene.unity`에서 Play한다.
2. 밤하늘·파스텔 하늘·정원 중 하나를 고른 뒤 **시작하기**를 누른다.
3. 카페 씬으로 이동한 뒤 기존 준비 조건을 만족하면 인물이 입장한다. 착석과 음성 연결이 끝나야 새 마이크 입력을 허용한다.
4. Scene_2를 직접 Play할 때는 운영자 화면의 **체험 시작**을 사용한다.

VR 입력은 컨트롤러 검지 트리거 또는 추적 손의 엄지·검지 집기를 놓을 때 확정한다. 누른 버튼과 놓은 버튼이 같아야 클릭한다.

관련 도구는 모두 **Tools > 다시봄** 아래에 있다.

- **시작화면 > 시작 씬 만들기**: 기존 시작 씬을 다시 만드는 초기 구성 도구다. 일반 Play를 위해 재실행할 필요가 없다.
- **그래픽 > 기능 > 운영자 화면 테마 적용**: 현재 열린 씬의 운영자 화면에 테마를 저장 가능한 상태로 적용한다. 결과를 보고 씬을 저장한다.
- **개발 도구 > 대화 검사 > 로컬 음성 검사 > 시작 화면·배경 전환**: 아래 loopback 검사다.
