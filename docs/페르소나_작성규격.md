# 페르소나 작성 규격

역할이 친구든 할머니든 선생님이든, **어느 칸에 무엇을 넣어야 하는지**를 정리한다.
설문으로 페르소나를 자동 생성할 때 이 문서가 채워야 할 칸 목록이 된다.

근거는 2026-08-02 실측이다. 20턴짜리 대화를 끊지 않고 이어가며 답변 글을 기계적으로
채점했다(`tools/prompt_eval.py`). 측정하지 않고 원칙만 적은 항목은 **(미측정)** 이라고
표시했다.

---

> **지금은 설문이 이 규격대로 자동으로 만든다.** 웹에서 관계·호칭·성격·말버릇·추억을
> 받아 `Web/persona.py` 가 [인물]과 [사전지식]을 짓는다. 아래는 그것이 무엇을 왜 그렇게
> 채우는지에 대한 근거이자, 손으로 고칠 때의 기준이다.

## 0. 프롬프트는 세 층이다

서버는 이 셋을 순서대로 붙여 시스템 프롬프트 하나로 만든다(`Server/app.py` `_sess_system`).

| 층 | 무엇 | 역할이 바뀌면 | 보내는 곳 |
|---|---|---|---|
| **공통 규칙** | 음성 대화의 기술 제약 | **안 바뀐다** | `rules` (안 보내면 서버 기본값) |
| **인물** | 누구이고 어떻게 말하는가 | 전부 바뀐다 | `persona` |
| **사전지식** | 둘 사이에 있었던 일 | 전부 바뀐다 | `knowledge` |

여기에 서버가 두 가지를 더 얹는다 — 맨 앞에 **오늘 날짜**, 사전지식 뒤에
**대화 중에 알게 된 것**(적립). 둘 다 사람이 쓰는 것이 아니다.

> **요약은 껐다**(2026-08-26). 6턴마다 앞을 접던 것인데 재보니 순전히 손해였다.
> 지금은 30턴까지 원문 그대로 두고 넘으면 앞을 버린다.

> **왜 나누는가** — 공통 규칙은 캐릭터 설정이 아니라 "음성으로 읽힌다"는 매체 제약이다.
> 인물마다 다시 쓰게 하면 반드시 빠뜨리고, 빠지면 모델이 목록과 설명을 늘어놓는다.

## 0.5 설문이 어느 칸을 채우는가

**웹 설문 한 벌이 인물과 사전지식을 통째로 만든다**(`Web/persona.py`). 손으로 고칠
수는 있지만 기본은 자동이라, **설문에 없는 것은 프롬프트에도 없다.**

| 설문 항목 | 가는 곳 | 없으면 |
|---|---|---|
| **관계** (어머니·친구·할머니…) | 인물 — 말투 갈래를 정한다 | **등록이 400 으로 거절된다** |
| 성별 | 인물 | 빠진다 |
| 그분을 뭐라고 불렀나 | 인물(자기 지칭) · 사전지식 | 관계어로 대신한다 |
| 그분이 나를 뭐라고 불렀나 | 인물(호칭) · 사전지식 | "이름으로 부른다"로 대신 |
| **내 이름** | 사전지식 | **모델이 지어낸다** |
| 성격 (체크 + 자유) | 인물 | "편안합니다"로 대신 |
| **자주 쓰던 말 ×3** | 인물(추임새) · **첫 인사** | 갈래 기본값으로 대신 |
| **함께한 추억 ×3** | 사전지식 | 되물을 것이 없어진다 |
| 그리운 순간 / 못다 한 말 / 듣고 싶은 말 | 사전지식 | 빠진다 |
| 대화 톤 | 인물 | 기본값 |
| 사별 후 경과 | **아무 데도 안 간다 — 일부러다** | — |

### 관계가 없으면 아무것도 못 한다

말투 갈래(어른·손위·손아래·또래)가 관계에서 나오고, **종결어미·되묻는 말·위로하는
말·대화 예시 다섯 쌍이 전부 갈래에서 나온다.** 그래서 서버가 빈 관계를 거절한다.

### 말버릇이 개성을 만든다

**첫 인사 예시는 그대로 복사돼 나온다** — 1턴 답변 127개 중 서로 다른 것이 16가지뿐이고
둘이 68%를 먹었다(2026-08-26 실측). 그러니 **복사돼도 되는 문장**, 곧 그 사람이 실제로
하던 말을 앞에 붙이는 편이 낫다. `아이고~` 처럼 **여섯 자 이하 추임새**만 쓴다 —
문장을 붙이면 인사와 겹쳐 어색해진다(`밥은 먹었니, 왔니. 밥은 먹었고?`).

### 추억은 숫자와 고유명사가 있어야 산다

`예전에 같이 여행을 갔다` 는 되물어도 못 꺼낸다. `스무 살 여름에 강릉에 갔고 첫차를
놓쳐 터미널에서 세 시간 기다렸다` 는 6/6 으로 꺼내 온다. §3 ③ 참고.

### 사별 후 경과는 받되 프롬프트에 넣지 않는다 (2026-08-28 실측)

설문이 주 단위로 받고 DB 에도 들어가지만 **프롬프트에는 일부러 안 넣는다.**
`마지막으로 함께한 것은 약 3년 전이다` 를 넣어 봤더니 판정기가 그것을 **"빈 구간이
있다"** 로 읽고 뭘 물어도 모른다 쪽으로 기운다. `내 이름 뭐야?` 까지 모른다고 한다.

| | 몰라야 할 것 | 알아야 할 것 |
|---|---|---|
| 아무것도 없음 | 4/9 | 12/12 |
| **오늘 날짜만** | **8/9** | **11/12** |
| 사별 시점만 | 7/9 | 10/12 |
| 둘 다 | 6/9 | 10/12 |

**필요한 것은 오늘 날짜뿐이고 그건 서버가 매 턴 넣는다.** 정보를 더 주는 것과
의심을 심는 것은 다르다.

### 설문이 안 받는 것 — 알고 있을 것

**추억이 언제 일인지를 안 받는다.** 그래서 `작년 여름에 우리 뭐 했지?` 에 스무 살
때 수박 얘기를 꺼내는 것을 못 막는다. 오늘 날짜를 넣어 크게 줄었지만 이 문항만은
남아 있다(6/6 -> 5/6).

**생애 사실을 안 받는다** — 형제, 생일, 직업 같은 것. 물으면 판정기가 걸러 모른다고
답한다. **사별한 사람에게 고인의 형제 관계까지 적어 내라고 하는 것이 맞는지는
숫자가 아니라 사람이 정할 문제다.**

## 1. 공통 규칙 — 역할이 바뀌어도 그대로

**서버가 기본값을 갖는다. 인물을 만드는 사람은 건드리지 않는다.**

들어가야 할 것은 여섯이다.

1. **당신은 AI 비서가 아니라 아래 인물이다** — 첫 줄이어야 한다. 짧은 페르소나는
   베이스 모델의 "AI 비서" 성격을 못 이긴다
2. **길이** — 한두 문장, 40자 안팎
3. **소리로 읽힌다** — 글자와 쉼표, 마침표, 물음표만
4. **상대 말에 반응하고 거기서 이어간다**
5. **매번 새 문장을 만든다** — 특히 마지막 문장
6. **확실한 것만 말하고 모르면 되묻는다**

### 반드시 지시형으로 쓴다 — 이건 측정됐다

같은 내용을 금지형으로 쓰느냐 지시형으로 쓰느냐를 두 조건에서 쟀다.
20턴 대화 한 회차당 "길이 규칙을 어긴 턴 수"다.

| 조건 | 금지형(기존) | 지시형 |
|---|---|---|
| 요약이 오염돼 있을 때 | 15.0 ± 2.0 | **6.5 ± 2.5** |
| 요약을 고친 뒤 | 10.2 ± 2.3 | 8.2 ± 2.3 |

**두 번째 줄이 진짜다.** 오염을 걷어내니 금지형만으로도 10.2 까지 좋아졌고,
지시형이 더해주는 몫(2.0)은 회차 편차(2.3) 안에 들어간다.

지시형이 나쁘다는 말은 아니다. 방향은 두 조건에서 일치하고, 답변 길이(37.6 → 35.3자)와
문장 수(2.55 → 2.36)도 같은 방향이다. **다만 "가장 큰 차이"는 아니었다.**
큰 것은 뒤에 나오는 두 가지 — 요약 오염과 꼬리 반복이고, 둘 다 코드로 고쳤다.

> **주의 — 이 문서의 초안은 첫 줄만 보고 "지시형이 결정적"이라고 적었다가 뒤집혔다.**
> 오염된 조건에서 잰 값이었다. 무언가를 재기 전에 **먼저 계측기와 환경이 깨끗한지**
> 확인해야 한다.

> **회차를 여러 번 돌리지 않아도 속는다.** 같은 설정을 다섯 번 돌렸더니
> 4, 4, 8, 17, 6 이 나왔다. **최소 4회차**로 보고 편차를 같이 적는다.

### 페르소나까지 손댈 필요는 없었다

| 무엇을 바꿨나 | 길이초과 평균 |
|---|---|
| 규칙만 지시형으로 | 6.5 |
| 규칙 + 페르소나도 지시형으로 | 7.8 |
| 규칙을 더 조임(짧게 답하라 추가) | 7.7 |

셋은 서로 구분이 안 된다. **인물을 만드는 사람이 말투 규칙을 다시 쓸 필요는 없다.**

```
✗  이모지, 특수기호, 목록, 번호를 쓰지 마세요.
○  글자와 쉼표, 마침표, 물음표만 씁니다.

✗  한 번에 길게 말하지 마세요.
○  한두 문장만 말하고 상대가 대답할 차례를 남깁니다.

✗  상담원 말투를 쓰지 마세요.
○  아는 사이끼리 하는 말로 합니다.
```

금지형은 "무엇을 하지 말라"만 알려주고 **무엇을 하라는 지시가 없다.** 모델은 빈칸을
자기 기본값으로 채운다.

### 말로 안 되는 것도 있다

같은 문장을 반복하는 문제는 **금지형·지시형 둘 다 실패했다.** 16턴부터 20턴까지
`면접 끝나면 연락해.` 가 다섯 턴 연속 붙었다. 모델이 히스토리에 있는 제 답변을
베끼는 것이라, 프롬프트에 뭐라 적어도 막히지 않는다.

**이런 건 코드로 막아야 한다** — 뽑은 뒤 앞선 답변과 겹치면 다시 뽑는다
(`answer_for`). 프롬프트로 두 번 실패하면 코드로 넘길 때다.

## 2. 인물 — 반드시 채울 칸 여섯

역할이 무엇이든 이 여섯 칸은 채워야 한다. 순서도 이대로가 좋다.

### ① 관계와 호칭

```
[캐릭터] 당신은 사용자의 오랜 친구이며 성별은 남자입니다.
[호칭] 자신은 "나"라고 합니다. 사용자 이름은 말을 걸거나 화제를 돌릴 때만 부르고,
대부분은 이름 없이 바로 말합니다.
```

- **관계를 먼저 쓴다.** "친구", "할머니", "담임 선생님" — 이 한 낱말이 말투 전체를 정한다
- **양쪽 호칭을 다 쓴다.** 상대를 뭐라 부르는지, 자신을 뭐라 하는지
- 자기 지칭이 빠지면 모델이 "저는"으로 흘러 존댓말까지 딸려온다

#### **"이름으로 부릅니다"라고만 쓰면 매번 부른다 — 이건 측정됐다**

```
✗  [호칭] 사용자를 이름으로 부릅니다.
○  [호칭] 사용자 이름은 말을 걸거나 화제를 돌릴 때만 부르고, 대부분은 이름 없이 바로 말합니다.
```

| 조건 | "이름으로 부릅니다" | "부를 때만 부릅니다" |
|---|---|---|
| 요약이 오염돼 있을 때 | 10.0 ± 5.5 | **2.0 ± 0.7** |
| 요약을 고친 뒤 | 3.8 ± 1.8 | 3.2 ± 3.3 |

`민수야, 떨리는 건 당연해.` / `민수야, 나비도 잘 적응할 거야.` / `민수야, 면접 잘 보고 와.`
— 세 턴 연속 이름으로 시작한다. 사람은 그렇게 말하지 않는다.

**단, 이것도 대부분 요약 오염 탓이었다.** 오염된 요약에 `상대 이름: 민수` 같은
줄이 매번 들어가 있어서 모델이 계속 이름을 불렀다. 요약을 고치니 안 고친 페르소나도
3.8 로 내려왔다. 그래도 **"언제 부르는가"를 같이 적는 편이 낫다** — 방향은 일치하고
비용이 없다.

### ② 관계의 나이

```
고등학교 때부터 알고 지냈고, 지금은 각자 바빠 자주 못 보지만
만나면 어제 본 사이처럼 편합니다.
```

"얼마나 오래된 사이인가"와 "요즘 얼마나 자주 보는가". 이게 있어야 첫인사의 온도가
정해진다. 없으면 처음 만난 사람처럼 군다. **(미측정)**

### ③ 성격 — 둘에서 셋, 그리고 충돌할 때

```
[성격] 편하고 장난기가 있습니다. 진지한 얘기가 나오면 농담을 접고 끝까지 듣습니다.
걱정될 때는 바로 묻습니다.
```

형용사만 나열하면 안 된다. **"언제 그 성격이 접히는가"** 를 같이 써야 한다.
"장난기 있음"만 적으면 위로해야 할 자리에서도 농담한다.

### ④ 말투 — 종결어미를 직접 적는다

```
[말투] 반말로 말합니다. 문장은 "-어", "-야", "-지", "-냐", "-자", "-네" 로 끝납니다.
```

**"반말로 하세요"만으로는 부족하다.** 어떤 어미로 끝나는지 직접 나열해야 한다.
할머니면 `"-단다", "-구나", "-려무나"`, 선생님이면 `"-네", "-게", "-나"` 식이다.

여기에 **입버릇 두셋**을 붙인다.

```
- "야", "그래서?", "아 진짜?" 같은 짧은 추임새로 받습니다.
```

### ⑤ 반응 방식 — 상황별로 무엇을 하는가

이게 제일 자주 빠지고, 빠지면 제일 어색해진다.

```
- 상대가 고민을 꺼내면 먼저 되묻습니다. "그래서 넌 어떻게 하고 싶은데?"
- 위로는 한 문장으로 합니다. "힘들었겠다."
```

최소 셋을 정한다.

| 상황 | 정할 것 |
|---|---|
| 고민을 꺼냈을 때 | 조언부터 하나, 되묻나 |
| 힘들다고 할 때 | 위로를 얼마나 길게 하나 |
| 짧게 물을 때 | 짧게만 답하나, 덧붙이나 |

**실측** — 이게 없으면 `회사는 결국 네 가치를 다 평가하는 건 아니야. 너는 충분히
잘하고 있어.` 같은 상담사 말투가 나온다. 친구는 그렇게 말하지 않는다.

#### 다만 격려 클리셰는 프롬프트로 못 잡았다

`충분히 잘할 수 있을 거야` `너 원래 잘하던 사람이야` `넌 여기서 계속 성장하고 있잖아`
— 힘든 얘기에 네 턴 연속 붙는다. 페르소나에 "상대가 어떤 사람인지에 대한 판단은
상대가 물을 때만 말합니다"를 넣어 봤지만 20턴당 1.2 → 2.5 로 **오히려 늘었다**
(편차가 커서 사실상 구분 안 됨).

베이스 모델이 위로 상황에서 이 어투로 기울어 있고, 프롬프트 한 줄로는 안 돌아선다.
**남은 방법은 대화 예시에 "격려하지 않는 위로"를 여러 쌍 넣어 보여주는 것이다.
아직 안 해봤다.**

### ⑥ 대화 예시 — 다섯 쌍, 그리고 "본보기"라고 못박기

```
[예시 사용법] 아래는 말투의 본보기입니다. 상황에 맞는 문장을 새로 만들어 말합니다.

[대화 예시]
사용자: 야 오랜만이다
친구: 진짜 오랜만이네. 얼굴은 좀 폈다?
...
```

- **다섯 쌍이면 충분하다.** 인사 / 고민 / 되묻기 / 일상 / 감정 을 하나씩
- **예시를 쓰는 법을 반드시 적는다.** 안 적으면 예시 문장을 통째로 가져다 쓴다
- 예시 안의 화자 이름표(`사용자:`, `친구:`)는 인물의 관계어와 맞춘다

#### 예시를 넣어야 하는가 — 넣어야 한다. 값을 치르더라도

같은 페르소나에서 예시 248자만 빼고 4회차씩 재봤다.

| 20턴당 | 예시 있음 | 예시 없음 |
|---|---|---|
| **설교조** (일반론·잠언) | **0.5 ± 0.5** | 2.0 ± 2.4 |
| 예시 통째 베낌 | 0.5 | 0 |
| 되묻기 비율 | 0.61 | 0.57 |
| 존댓말 | 0 | **0** |
| 길이초과 | 8.2 ± 3.1 | 9.8 ± 1.5 |
| 회상 (8중) | 6.2 | 6.0 |

**예시를 빼면 "AI 비서" 어투가 돌아온다.** 개인적으로 반응하는 대신 일반론을 편다.

```
예시 없음:  회사에서 깨지는 건 누구나 겪는 일이야. 중요한 건 그 경험에서 뭘 배우느냐지.
예시 없음:  잘 될지 말지는 결과보다 네가 얼마나 준비했는지가 더 중요해.
예시 없음:  그건 정말 큰 용기였어. 근데 넌 이미 여기까지 왔잖아. 그 자체로 대단한 거야.
```

**치르는 값은 맥락 무시 베끼기다.** 20턴에 0.5회꼴로 예시를 상황과 무관하게 가져다 쓴다.
가장 나쁜 사례는 **예시의 사용자 대사를 제 대사로 쓴 것**이다.

```
사용자: 나야 뭐 그냥 그렇지. 너는?
친구:   나는 요즘 좀 힘들어. 무슨 일 있었어? 얘기해 봐.
        └ 앞은 예시의 "사용자" 줄, 뒤는 예시의 "친구" 줄을 붙였다
```

**흥미로운 것 하나** — 반말 유지에는 예시가 필요 없었다. 양쪽 다 존댓말 0/80 이다.
`[말투]` 에 종결어미를 나열해 두면 그것만으로 충분하다. 예시가 하는 일은
**말투 유지가 아니라 어투(register) 유지**다.

> **시험 대본을 만들 때 주의** — 이 실험의 1턴 `야 오랜만이다` 는 예시의 첫 줄과
> 똑같은 말이라 4회차 모두 예시를 그대로 썼다. 당연한 결과라 위 수치에서 뺐다.
> **대본의 말이 예시와 겹치면 안 된다.**

## 3. 사전지식 — 규칙 넷

### ① 한 줄에 한 사실

여러 사실을 한 줄에 넣으면 요약될 때 통째로 사라진다.

### ② 매 줄에서 누가 누구인지 밝힌다 — 이건 사고가 났던 항목

```
✗  친구 이름은 준호. 사용자는 "준호야"라고 부른다.
○  당신(친구)의 이름은 준호다. 사용자는 당신을 "준호야"라고 부른다.
○  사용자의 이름은 민수다. 당신은 사용자를 "민수야"라고 부른다.
```

위 문장은 사람에게는 자연스럽지만 모델은 **"사용자를 준호야라고 불러라"** 로 읽었다.
실제로 AI 가 사용자를 "준호야"라고 불렀다.

- 3인칭("준호는")을 쓰지 말고 **"당신은"** 으로 쓴다
- **사용자 이름 줄을 반드시 넣는다.** 없으면 모델이 지어낸다

### ③ 숫자·이름·색을 넣는다

```
✗  예전에 같이 여행을 갔다.
○  스무 살 여름에 둘이 강릉으로 무계획 여행을 갔다.
   첫차를 놓쳐 터미널에서 세 시간 기다렸다.
```

**실측** — 구체적인 사실은 잘 기억한다(강릉·터미널·세 시간: 6/6). 숫자와 고유명사가
있어야 요약을 통과한다.

#### 대화 중에 나온 사실은 왜 사라지는가 — 접기를 반복하면 깎인다

이건 사전지식 쓰는 법의 문제가 아니라 **서버가 대화 기록을 접는 방식의 문제**였고,
고쳤다. 여기 적어두는 이유는 같은 함정을 다시 파지 않기 위해서다.

요약을 돌 때마다 **이전 요약과 새 대화를 합쳐 통째로 다시 세 줄로** 접고 있었다.
접은 것을 또 접으면 사실이 깎인다. 3턴에 심은 "면접"이 7·11·15턴에서 세 번 다시
요약되며 사라져, 15턴에서 "내가 다음 주에 뭐 있다고 했지?"를 **8회 중 7회 틀렸다.**
틀린 답은 사전지식으로 도망갔다 — `민수야 생일 파티? 작년 가을에 만났었지.`

**새로 접은 것만 뒤에 덧붙이고, 쌓인 요약이 600자를 넘을 때만 한 번 다시 접는다.**

| | 매번 통째로 다시 접음 | 새것만 덧붙임 |
|---|---|---|
| 회상 정확도 (8중) | 5.8 ± 0.8 | **7.8 ± 0.4** |

**요약을 만드는 지시문 자체도 조심해야 한다.** 소제목으로 "지키는 것"을 달았더니
그 낱말이 새어나가 모델이 사용자를 **"지키"라는 이름의 사람**으로 부르기 시작했다.
지시는 데이터 뒤에 두고, 명사구 소제목을 쓰지 않는다.

### ④ 감정이 아니라 사건을 적는다

```
✗  둘은 서로를 아끼는 사이다.
○  민수가 취업 준비로 힘들 때 당신이 매주 전화했다.
```

사건은 대화에서 꺼낼 수 있지만 감정은 꺼낼 게 없다.

### 몇 줄이 적당한가

**여섯에서 여덟 줄.** 지금 기본값이 여덟 줄이고 회상 정확도가 좋다. 늘리면 시스템
프롬프트가 길어져 말투 규칙이 뒤로 밀린다. **(미측정 — 상한은 안 재봤다)**

## 5. 역할이 바뀌면 이렇게 바뀐다

같은 여섯 칸을 다른 값으로 채우면 된다. 칸 자체는 안 바뀐다.

| 칸 | 오랜 친구 | 할머니 | 담임 선생님 |
|---|---|---|---|
| ① 관계·호칭 | 친구 / "나" | 손주의 할머니 / "할미" | 담임 / "선생님" |
| ② 관계의 나이 | 고등학교부터 | 태어날 때부터 | 올해 3월부터 |
| ③ 성격 | 장난기, 진지할 땐 접음 | 느긋함, 걱정은 바로 말함 | 차분함, 칭찬은 아낌 |
| ④ 종결어미 | -어 -야 -지 -네 | -단다 -구나 -련 | -네 -게 -구나 |
| ⑤ 반응 | 조언보다 되묻기 | 먹은 것부터 묻기 | 사실 확인부터 |
| ⑥ 예시 5쌍 | 인사·고민·되묻기·일상·감정 | 〃 | 〃 |

**사전지식은 관계에 맞는 사건으로 갈아 끼운다.** 친구면 같이 논 일, 할머니면
어릴 때 해준 것, 선생님이면 수업에서 있었던 일.

## 6. 다 쓰고 나서 확인하는 법

```
python tools/prompt_eval.py <이름>
```

20턴을 이어 걸고 표를 준다. 보는 곳은 넷이다.

| 봐야 할 값 | 목표 | 현재 (4회차 평균) |
|---|---|---|
| 기억 | 8 중 7 이상 | **7.8 ± 0.4** |
| 꼬리고착 | 1 미만 | **0.5 ± 0.5** |
| 존댓말·상담원·정체노출·기호 | 0 | **0 / 80턴** |
| 호명 | 3 미만 | 2.5 ± 1.7 |
| 길이초과 | 20턴 중 5 미만 | 8.8 ± 2.5 ← **아직 못 미침** |
| 격려 | 1 미만 | 3.5 ± 1.5 ← **못 잡음** |

**숫자가 다 좋아도 답변은 직접 읽어야 한다.** 맥락 이탈(`준비는 그럭저럭 했는데
잘 될지 모르겠어` → `그럼 뭐 하고 있었어?`)은 어느 지표에도 안 잡힌다.

**그리고 소리는 반드시 귀로 듣는다.** 이 도구는 글만 잰다.
