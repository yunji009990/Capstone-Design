# 얼굴·몸체 결합 상태의 체형 미리보기

기준일: 2026-10-24. 실제 카페와 단독 미리보기에서 결합된 얼굴을 보면서 체형·전체 크기·머리 크기와 연결 위치를 조절하는 Unity Editor 도구다.
마지막 로컬 모델 또는 현재 등록 모델을 읽어 표시하며, 새 Tripo 생성이나 서버 모델 재결합을 요청하지 않는다.

## 여는 방법

1. 카페 `Scene_2`에서 Play를 종료한다.
2. **Tools > 다시봄 > 캐릭터 > 얼굴·몸체 비율 조절 씬 열기**를 선택한다.
3. 카페에서는 그 공간을 유지하며 **얼굴·몸체 비율 조절** 창과 착석 미리보기가 열린다. 마지막 로컬 모델이 있으면 재사용하며, 없으면 현재 등록 모델을 가져온다.
4. **확인 자세**에서 `T포즈 / 서있기 / 앉기`를 고른다. 단독 미리보기에서는 T포즈도 확인할 수 있으며, 양팔·손목·손가락을 대칭으로 편다. 정면·측면·뒤·얼굴/어깨·목 연결부 확대 버튼으로 확인한다.
5. 슬라이더나 숫자를 바꾼다. Play 없이 바로 보이며 **체형 설정을 Inspector에서도 열기**로 기존 Inspector도 사용할 수 있다.

이미 조절 중이면 같은 메뉴는 현재 창을 다시 연다. 씬 자산을 직접 열거나 스크립트를 다시 컴파일하면 마지막 로컬 모델을 복원한다.
다른 결합 모델은 **로컬 결합 GLB 열기**로 선택할 수 있다. 서버 인물이 바뀐 경우 **현재 등록 모델 다시 가져오기**를 누른다.
단독 씬은 빌드 목록에 넣지 않은 Editor 작업용 씬이다. 저장된 단독 씬에는 카메라·중립 조명·바닥만 포함한다.

## 실제 카페에서 크기 확인

- **카페에서 보기 · 실제 의자에 앉히기**로 `Scene_2`에서 비교하고, **단독 미리보기로 돌아가기**로 중립 배경으로 전환한다. 같은 미리보기 프로필을 사용한다.
- 두 배경 모두 카페 `PersonaSpawner`의 `targetHeightMeters`와 `scaleMultiplier`를 읽어 같은 순서로 적용한 뒤 체형 프로필을 적용한다. 10월24일 설정은 키 정규화0(원본 사용)·추가 배율1.2다.
- 카페의 앉은 자세는 실제 `PersonaArrival`의 의자·오프셋·방향·착석 클립을 사용한다. 서있기와 T포즈는 이동 경로의 마지막 바닥 지점에서 확인한다.
- **체험자 자리에서 보기**는 VR 카메라의 수평 위치·방향을 사용한다. HMD를 쓰기 전 카메라는 바닥에 있으므로 **미리보기 눈높이 (m)**로 바닥 기준 높이를 지정한다. 기본1.2m는 앉은 시점이며 실제 HMD 추적 결과는 아니다.
- 슬라이더를 움직여도 카메라는 자동 확대/축소하지 않는다. 크기 차이를 가구와 비교할 수 있고, 서있는 모델은 크기를 바꿔도 발을 바닥에 맞춘다. 측면은 카페 안쪽에서 본다.
- 창에 현재 자세의 메시 높이를 cm로 표시한다. 앉은 높이는 신장과 다르므로 키 비교에는 **서있기**를 사용한다.
- 카페 미리보기 모델·추가 카메라는 저장 제외 객체다. 기존 카페·테이블·담장·유리·원래 VR 카메라와 공용 체형 기본값은 바꾸지 않는다. 기본 체형 반영은 아래 버튼을 명시적으로 눌렀을 때만 수행한다.

## 조절 범위와 저장

| Blend Shape | 음수 / 양수 |
|---|---|
| 상체 폭 | 가슴·등의 좌우 폭을 좁게 / 넓게 |
| 상체 두께 | 몸통을 얇게 / 두껍게 |
| 허리 폭 | 허리를 좁게 / 넓게 |
| 배 볼륨 | 배 앞쪽을 들어가게 / 나오게 |
| 팔 굵기 | 팔·소매를 가늘게 / 굵게 |
| 다리 굵기 | 다리·바지를 가늘게 / 굵게 |

위6개 범위는−1~1이고0은 제작 원본이다. 폭·두께를 조절하며, 이 키들로 손·신발·얼굴과 본 배치를 바꾸지 않는다.
6개 키가 있는 몸체와 머리 본에 연결된 별도 생성 머리를 대상으로 한다.

| 추가 설정 | 범위·의미 |
|---|---|
| 전체 크기 (배율) | 0.7~1.3, 기본1. 몸체·머리·리깅을 함께 균일하게 확대/축소 |
| 머리 크기 (배율) | 0.75~1.35, 기본1. 목 연결부를 기준으로 얼굴·머리카락 크기 조절. 1.1은110% |
| 머리 높이 (키 비율) | −0.03~0.05, 기본0. 자동 결합 보정에 더하는 높이. 0.01은 몸체 원본 높이의1% 위로 |
| 머리 앞뒤 (키 비율) | −0.04~0.04, 기본0. 양수는 얼굴 방향, 음수는 뒤쪽 |

머리3개는 인스턴스 전용 Blend Shape이며, 전체 크기는 리깅도 같이 유지하도록 루트 배율로 처리한다.
팔다리 길이를 개별 조절하는 기능은 없다. 전체 크기는 머리에도 적용되며, 머리 배율로 상대 비율을 추가 조절한다.

| 버튼·설정 | 동작 |
|---|---|
| 미리보기 체형 저장 | `Assets/Settings/PersonaBodyShapePreview.asset`에 체형6개·추가4개 값 저장 |
| 현재 기본 체형으로 되돌리기 | 현재 공용 기본 설정의10개 값을 미리보기로 복사 |
| 기본 체형에 적용 | 미리보기 값을 `Assets/Resources/PersonaBodyShape.asset`으로 복사·저장. 기본 설정을 사용하는 카페 모델의 다음 로드부터 적용 |

슬라이더 편집·설정 복사는 Undo를 지원한다. 기본 체형에 적용하기 전에는 공용 기본값을 바꾸지 않는다.
등록 인물별 체형 자동 저장과 서버 GLB 자체의 수정은 이 기능에 포함하지 않는다.

## 모델·리깅 처리

- Scene_2의 모델 로더에서 등록 주소·세션 선택을 읽고 기존 등록 API로 완성 GLB를 받는다. 토큰·인물 ID는 씬이나 로그에 기록하지 않는다.
- GLB는 Git 제외 `tools/_work/body_shape_preview/current_model.private.glb`에만 캐시한다. 모델·메시·재질 미리보기는 씬 저장 대상에서 제외한다.
- 기존 glTFast, `PersonaHumanoid.TryPrepare`와 기준 자세 자산, `PersonaBodyShapeController`를 재사용한다.
- `PersonaCollarTemplate`이 원본 기본 FBX의 옷깃을 이용해 수평으로 잘린 상단만 복원한다. 원래 몸체 정점과6개 키는 보존한다.
- `PersonaModelProportions`가 생성 머리의 목 절단면을 머리 본 접합점에 맞춰 머리 전체를 이동한다.
  얼굴형·정점 수·UV·법선·삼각형·가중치·재질을 유지하며, 덧댄 목 원통과 별도 피부색 재질은 제거했다.
  원인과 복원 방식은 [머리·목 결합 보정](머리_목_결합_수정_20261024.md)을 따른다.
- 머리 크기·높이·앞뒤3개 키는 목 아래 정점을 고정하고 위쪽에 섞는다. 본의 로컬 위치·회전·개별 배율과 Avatar는 변경하지 않는다.
  전체 크기는 로더의 기존 키 정규화 이후 추가 배율로 적용한다. 설정을 공용 기본값에 복사하면 카페의 다음 모델 로드에도 사용한다.
- T포즈는 표시용 본 회전만 조절한다. 애니메이션 기준 자세 자산·서버 결합 스크립트·원본 FBX·등록 GLB는 보존한다.
- 자세는 수동 PlayableGraph로 샘플링한다. 화면 밖에서 렌더할 때 이전 스킨 행렬을 쓰지 않도록
  [`forceMatrixRecalculationPerRender`](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/SkinnedMeshRenderer-forceMatrixRecalculationPerRender.html)를 켠다.
  자세 적용 후 실제 스킨 정점으로 범위를 계산한다. 배율을 중복 적용하지 않고 얼굴과 발이 들어오게 화면을 맞춘다.
- 씬 전환·Play 진입·컴파일·Editor 종료 시 이 도구가 만든 모델·Avatar·그래프·임포터를 정리한다.
