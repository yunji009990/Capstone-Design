## 1. 현재 동작

착석 후 사용자의 발화가 서버에서 확인되면 작은 끄덕임으로 듣고 있다는 신호를 준다.
마이크 음량만으로 반응하거나 모든 문장에 고개를 끄덕이지 않는다.
기존 시선·호흡·착석 고개 보정 다음에 회전을 얹으며 본 위치·스킨·체형 키는 바꾸지 않는다.

| PersonaArrival 설정 | 현재 값 | 의미 |
|---|---|---|
| Auto Nod While Listening | 켬 | 자동 듣기 반응 |
| Nod After Listening Sec | 1.2초 | 반응할 확정 발화의 최소 길이 |
| Nod Min/Max Gap Sec | 4.5~7초 | 반응 사이의 무작위 최소 간격 |
| Listening Nod Degrees | 4.5도 | 클립이 없을 때 절차적 끄덕임의 최대 각도 |
| Listening Nod Seconds | 0.9초 | 고개를 내렸다 원래 자세로 돌아오는 시간 |

현재 `nodClip`은 비어 있으며 절차적 회전을 사용한다. 목35%·머리65%로 나눠 회전한다.
인물이 말하거나 다른 제스처가 있으면 새 반응을 막고, 진행 중인 작은 회전은 약0.2초 안에 걷는다.
입장·걷기·인사·착석 중과 체험 종료 후에는 적용하지 않는다. 기존 말하기 제스처의25% 선택 정책은 보존했다.

서버는 입력 검증을 끝낸 뒤 `speech.started`와 `speech.stopped`를 연달아 보낸다.
따라서 `isRecording=true`가1.2초 유지된다고 가정하면 실제 대화에서 반응하지 않는다.
확정 전사의 입력 턴과 실제 발화 길이를 읽어 반응을 예약하고 동일 입력을 한 번만 처리한다.
자막 표시를 꺼도 내부 전사 상태를 사용한다. **발화 확인 직후의 반응**이며 음성 내용·감정 인식 기능은 아니다.
본답변 음성이 먼저 시작되면 끄덕임을 위해 음성을 늦추지 않고 반응을 건너뛴다.

## 2. 공간 음향 설정

캐릭터 로더의 `PersonaVoiceSpatialAudio`에서 조절한다.

| 설정 | 현재 값 | 의미 |
|---|---|---|
| Spatial Voice | 켬 | 보이는 인물의 머리 위치에서 음성 재생 |
| Head Offset Meters | (0,−0.07,0)m | 머리 본에서 입 근처로 위치 보정. 인물 루트 방향을 사용하고 모델 배율은 곱하지 않음 |
| Min Distance | 1.5m | 이 거리까지 Unity 감쇠의 기준 음량 유지 |
| Max Distance | 18m | 선형 거리 감쇠의 최대 거리 |

설정은 Edit Mode에서 저장하면 유지된다. Play 중 조절은 체험 확인용이다.
모델이 없거나 숨겨져 있으면 음성 전용2D 재생으로 돌아간다.
컴포넌트를 비활성화하면 음원의 기존 위치·2D/3D·공간화·감쇠·도플러·spread 설정을 복원한다.
음량과 믹서 그룹은 변경하지 않는다. HRTF·거리 처리를 적용한 체감 음량은2D와 다를 수 있어 실제 장치에서 확인한다.

프로젝트에 이미 설정된 Meta XR Audio를 사용하며 패키지나 ProjectSettings는 변경하지 않았다.
`DialogueAudioPlayer`가2D를 강제로 지정하던 부분을 제거하고,
`spatialBlend=1`, `spatialize=true`, `spatializePostEffects=true`로 PCM 생성 이후 공간화를 적용한다.
그 순서가 없으면 먼저 적용된 좌우 차이를 커스텀 PCM 출력이 덮어쓸 수 있다.
설정 근거는 [Unity spatializePostEffects](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AudioSource-spatializePostEffects.html)와
[Meta 공간화 안내](https://developers.meta.com/vr/documentation/unity/meta-xr-audio-sdk-unity-spatialize/)다.
도플러는0으로 두어 걷기·머리 움직임이 음성의 높낮이를 바꾸지 않게 했다.
음원은 PersonaSpawner의 LateUpdate 이후 머리 위치를 읽는다.

## 5. 남은 장치 확인

실제 등록 목소리로 새 대화 왕복, HMD 착용 청취, 플레이어 빌드·GPU 성능 검사는 이번에 수행하지 않았다.
Scene_2 Play의 기본 등록 조회·모델 선로딩 외에 서버 재시작·배포·새 음성 합성·등록 자료 변경은 하지 않았다.

HMD에서 확인할 것은 다음과 같다.

1. 인물이 앉은 뒤1.2초 이상 말했을 때, 발화 확인 후 작은 반응이 가끔 나오는지 확인한다.
2. 인물이 말할 때 고개를 좌우로 돌려 목소리가 인물 쪽에 남는지, 음량이 충분한지 듣는다.
3. 답변 중 끼어들기·재개·종료 후 재시작에서 음성·고개 자세가 남지 않는지 확인한다.

반응을 더 작게 하려면 `Listening Nod Degrees`를 낮춘다. 너무 자주 보이면 `Nod Min/Max Gap Sec`를 늘린다.
이번 구현은 입모양·표정·음성 감정 추정이나 서버 모델 교체를 포함하지 않는다.
