# Unity 도구 사용법

기준일: 2026-10-25. 프로젝트 전용 메뉴는 **Tools > 다시봄** 한 곳에서 연다.
기존 `Tools > Persona`, `Dialogue`, `Tripo`와 최상단 `다시봄` 메뉴는 통합했다.
Unity·Meta XR·COZY·Feel 등 외부 패키지가 등록한 메뉴는 각 패키지의 위치를 따른다.
정리 직후54개였고, 얼굴·몸체 미리보기2개·로컬 체험 준비 검사1개·새 몸체 로컬 시험3개와
hj 병합의 시작 씬 구성·운영자 테마·시작 화면 검사3개를 추가해 **현재63개**다. Unity의 실제 메뉴 목록에서도63개를 확인했다.

## 자주 쓰는 기능

| 메뉴 (`Tools > 다시봄` 아래) | 기능·사용 조건 |
|---|---|
| **캐릭터 > 이동 경로 편집** | Scene 창에서 NPC의 바닥 경로와 중간 인사 위치를 편집. Play를 종료하고 사용 |
| 캐릭터 > 체형 조절 열기 | 상체·허리·배·팔·다리의 체형 설정을 Inspector에서 조절. Play 중에도 가능 |
| **캐릭터 > 얼굴·몸체 비율 조절 씬 열기** | 실제 카페 또는 단독 미리보기에서 체형6개 키와 전체 크기·머리 크기/높이/앞뒤 조절. 실제 의자·체험자 자리와 눈높이로 크기 비교. 별도 저장·공용 기본 체형에 적용 |
| 캐릭터 > 모델 미리보기 열기 | 로컬 GLB를 현재 씬 조명에서 확인. 창을 여는 것만으로 모델 생성 API를 호출하지 않음 |
| 캐릭터 > 전체 리깅 보기 | Play 중 불러온 캐릭터의 전체 본·관절 표시 |
| 캐릭터 > 리깅 표시 켜기·끄기 | `F8`로 리깅 표시 전환 |
| 캐릭터 > 새 몸체 로컬 시험 사용 | 이 PC의 Editor에서 현재 등록 모델과 일치하는 새 니트 몸체 시험본 사용·해제. 다음 Play에 적용하며 서버·빌드는 변경하지 않음 |
| **그래픽 > 배경 선택** | 밤하늘 카페·파스텔 하늘 카페·기존 정원 선택. Scene_2의 Edit Mode에서 사용 |
| **시작화면 > 시작 씬 만들기** | 배경 선택·시작 UI가 있는 StartScene을 다시 만드는 초기 구성 도구. 일반 실행은 저장된 StartScene을 Play |
| 그래픽 > 기능 > 운영자 화면 테마 적용 | 현재 씬의 운영자 UI에 테마 적용. 확인 후 씬을 저장하며 준비·시작 버튼 연결은 유지 |
| 그래픽 > 기능 > 유리 반사 조절 열기 | 두 창의 반사·투과 설정을 Inspector에서 조절. Play 중에도 열 수 있음 |
| 그래픽 > 기능 > 창가에서 보기 | Scene 창을 카페 내부의 창가 시점으로 이동 |
| 그래픽 > 기능 > 베이크 | 실내 조명 또는 실내 반사를 다시 계산. 반사 항목은 실내 기본 환경 반사 연결과 씬·자산 저장도 수행 |
| **대화·서버 > 서버 연결 상태 열기** | 웹·등록 서비스와 모델 작업자의 연결 상태 확인 |
| 대화·서버 > 진단 > 지금 문제 발생 표시 | 진행 중인 체험 로그에 문제 시점 표시. 체험을 중단하지 않음 |
| 대화·서버 > 진단 > 대화 로그 폴더 열기 | 이 PC의 대화 기록 폴더 열기 |
| 대화·서버 > 진단 > 로컬 진단 보고서 만들기 | 이 PC의 최신 로그를 분석해 보고서 생성 |

운영자 화면의 준비 재확인은 **체험 시작**에 통합했다. 미준비 상태에서 누르면 버튼 위에 빨간 미완료 항목을 표시한다.
실내 기본 환경 반사는 `Custom` + 기존 `CafeInteriorReflection.exr`를 사용하며 배경3종 전환에서도 유지한다.
창의 반사 강도는 기존 유리 반사 조절 창에서 조절한다. 설정·검사 범위는 [그래픽 현황](현재_구현_현황.md#scene_2-그래픽-현재-설정)을 따른다.

### 캐릭터 동작 Inspector 설정

Scene_2의 캐릭터 로더를 선택하면 다음 값을 조절할 수 있다. 저장할 값은 Edit Mode에서 바꾸고 씬을 저장한다.

| 컴포넌트·필드 | 현재 값·효과 |
|---|---|
| `PersonaArrival.walkSpeed` | `0.8`. 현재 `NaturalWalk` 보폭에 맞춘 이동 속도(m/s) |
| `PersonaArrival.sitDownPlaybackSpeed` | `1.3`. 별도 앉기 클립의 배속과 좌석까지의 위치 보간을 함께 조절 |
| `PersonaSpawner.stabilizeHeadWhileSitting` | 켬. 앉기 동안만 목·머리의 상대 회전을 안정화 |
| `PersonaSpawner.fillNeckInterior` | 켬. 모델 로드 시 열린 목 안쪽·어두운 내부 면을 주변 피부색으로 채움. 변경 뒤 Play를 다시 시작 |

시선·호흡·듣기 반응은 착석 뒤에도 유지한다. 목과 머리는 분리된 메시라 근접 시 약한 기하·명암 경계가 남는다.
[클립·목 내부의 구현·검사](머리_목_결합_수정_20261024.md#착석-배속인사-진입-손목목-내부-피부색--2026-10-25)를 따른다.

### 이동 경로 편집

1. `Scene_2`를 열고 Play를 종료한다.
2. **캐릭터 > 이동 경로 편집**을 연다. **위에서 보기**로 바닥을 내려다본다.
3. **점 편집**에서 점을 드래그한다. `Shift+클릭`은 마지막에 추가, `Ctrl+클릭`은 선 중간 삽입이다.
4. **경로 그리기**에서는 왼쪽 버튼을 누르고 새 동선을 그린다. 버튼을 놓으면 기존 경로를 교체한다.
5. **걷다가 인사**·**인사 위치 (%)**로 인사 지점을 정하고 **씬 저장**을 누른다.

경로가 없는 씬은 같은 창의 **기존 경로로 만들기**로 준비한다. 별도 준비 메뉴는 제거했다.
`Ctrl+Z`로 편집을 되돌릴 수 있다. 체형·유리는 각 Inspector의 설정 저장 버튼을 사용한다.

실행 조건·보고서의 의미는 각 기능 문서를 따른다. 메뉴가 보인다는 사실과 검사 통과는 별개다.

| 분류 | 포함된 기능 |

| 캐릭터 검사 | 불러온 서버 모델 상태, 입장 연출만 실행 (Play), 서버 모델 체형 변형 (Play) |
| 캐릭터 검사 | 새 몸체 상태 기록, 새 몸체 입장·착석 검사 (Play). [시험 범위·보관 위치](머리_목_결합_수정_20261024.md#새-니트-몸체의-unity-로컬-시험) |

| **대화 검사 > AI 테스트 씬 열기** | AI_Response_Test로 이동. 없는 경우 자동 생성하므로 별도 생성 메뉴는 없음 |

| 대화 검사 > 로컬 음성 검사 | 리샘플링 코어, 스트리밍 버퍼, 말끝 출력 파형, 일시정지·재개 경계, 전체 수신 재생 |

| 대화 검사 > 로컬 음성 검사 > 시작 화면·배경 전환 | 실제 시작 씬과 카페를 loopback에 연결해 배경3종·자동 시작 조건·테마·착석 후 입력·페이드 종료 검사. [실행 방법](hj_병합_20261024.md) |
| 대화 검사 > 최근 답변 비교 | 마지막 완료 답변의 같은 PCM을 스트리밍·AudioClip으로 다시 듣기, 다시 듣기 중지 |
| 대화 검사 > 재생 방식 비교 | 다음 Play부터 전체 수신 후 AudioClip 재생 또는 수신 즉시 스트리밍 선택 |
| **모델 검사 > 로컬 GLB 검사 씬 열기** | Tripo_Model_Test에서 로컬 모델·리깅·클립 검사. 단계·모델·클립 변경은 검사 창 안에서 수행 |
| **초기 설정·복구** | 입장 연출 초기 설정, 기본 몸체 재질·기준 자세 재연결, 바리스타 동작 재연결, 체험 연출 오브젝트 만들기, VR 잡기 참조 검사·복구 |
| **그래픽 > 기능 > 검사** | 현재 배경 촬영·검사, 배경 전환 보존 검사, 유리 반사 검사. 그래픽 기능 옆에 유지 |

**실제 서버 검사**는 Play와 준비된 서버를 사용한다. **로컬 음성 검사**는 해당 설정 파일·파형 또는
합성 입력을 사용하며 서버 대화 품질 판정과 다르다. `입장 연출만 실행`은 마이크·대화를 시작하지 않는다.
**초기 설정·복구**는 씬 연결이나 자산 값을 바꾸는 도구다. 경로·체형·유리의 일반 조절에는 위의 편집 도구를 사용한다.
