# 제거된 기능 · 원본 프로젝트 아카이브

voice_clone_studio를 **self-contained**로 정리하면서, 원본 두 프로젝트(`Audio extraction`,
`make_audioVoice/tts-benchmark`)를 폴더에서 제거하고 **필요한 런타임만** `engine/` 안으로
이동했다. 이 문서는 제거된 기능과 근거를 남긴다. 원본 문서 사본은 [archive/](archive/)에 보존.

## 현재 구성 (남은 것)
```
voice_clone_studio/
├── app.py, runners/, web/        # 통합 웹앱
├── engine/
│   ├── extraction/               # NeMo MSDD 추출 (nemo_env, nemo_conf 포함)
│   └── tts/                      # Qwen3-TTS 합성 (eval_env, adapters/qwen3tts, pipeline)
└── docs/
    ├── 제거된_기능.md (이 문서)
    └── archive/                  # 원본 문서 사본
```
- **추출 엔진: NeMo MSDD 만** (동시발화 검출 + 다중스케일 임베딩, 정밀)
- **TTS 모델: Qwen3-TTS 만** (Qwen/Qwen3-TTS-12Hz-1.7B-Base)

## 1. 제거된 추출 엔진 — ECAPA

| 항목 | 내용 |
|---|---|
| 무엇 | Silero VAD + ECAPA(SpeechBrain) 임베딩 + KMeans 군집 파이프라인 |
| 특징 | 가볍고 빠름. 화자별 연속 단일화자 구간에서 7~12초 클립 |
| 제거 이유 | NeMo가 동시발화(overlap)까지 검출해 더 정밀. 엔진 이원화 불필요 |
| 코드 | `engine/extraction/extract_speaker_ref.py`에서 ECAPA 파이프라인 삭제, NeMo가 쓰는 공용 헬퍼(디코드·SNR·클립·시각화)만 유지 |

NeMo 엔진 흐름은 [archive/audio_extraction_README.md](archive/audio_extraction_README.md) 참고.

## 2. 제거된 TTS 모델 (Qwen3-TTS 외 4종)

원본 `tts-benchmark`는 zero-shot 한국어 TTS 5종을 벤치마크했다. 그중 **Qwen3-TTS만 유지**하고
나머지 4종의 어댑터·가상환경·모델 가중치를 제거했다.

### 벤치마크 종합 순위 (제거 근거)
전체 결과: [archive/tts_benchmark_report.md](archive/tts_benchmark_report.md)

| 순위 | 모델 | Score | SECS(유사도) | CER(발음) | 실패율 | 상태 |
|---|---|---|---|---|---|---|
| 1 | cosyvoice2 | 0.971 | 0.771 | 0.049 | 3.7% | ❌ 제거 |
| 2 | **qwen3tts** | 0.912 | 0.723 | **0.044** | **0.0%** | ✅ **유지(메인)** |
| 3 | chatterbox | 0.834 | 0.737 | 0.040 | 0.0% | ❌ 제거 |
| 4 | f5tts_ko | 0.753 | 0.716 | 0.054 | 0.4% | ❌ 제거 |
| 5 | gptsovits | 0.000 | 0.528 | 0.220 | 0.0% | ❌ 제거 |

### 왜 1위(cosyvoice2)가 아니라 Qwen3-TTS를 메인으로?
- **실사용 조건(임의 오디오에서 추출한 레퍼런스)에서 더 강건**: Qwen3-TTS는 LLM 기반이라
  레퍼런스의 "목소리 정체성"만 뽑아 깨끗하게 생성 → **레퍼런스에 잡음이 있어도 출력이 깔끔**.
  CosyVoice2는 레퍼런스의 녹음 환경(잡음)까지 복제해 "지지직" 아티팩트가 생기기 쉬움.
- Qwen3-TTS는 **발음 정확도(CER) 최고, 실패율 0%**.
- CosyVoice2가 종합 1위인 건 화자 유사도 가중치 때문(녹음 환경까지 똑같이 복제).

### 각 모델 요약
| 모델 | 특징 | 제거 |
|---|---|---|
| cosyvoice2 | 유사도 최고, 그러나 레퍼런스 잡음 복제(지지직) | ❌ |
| chatterbox | 무난, ref_text 불필요, PerTh 워터마크 | ❌ |
| f5tts_ko | F5-TTS 한국어 체크포인트, flow 기반 | ❌ |
| gptsovits | 중국어 백본 + AR 환각으로 한국어에서 "다른 말" 생성, 품질 최하 | ❌ |

벤치마크 설계·모델 목록 상세: [archive/tts_benchmark_spec.md](archive/tts_benchmark_spec.md),
[archive/tts_benchmark_README.md](archive/tts_benchmark_README.md)

## 3. 되돌리려면
- 제거된 모델을 다시 쓰려면 해당 어댑터(`adapters/<id>/`)와 그 venv·모델을 재설치하고
  `engine/tts/configs/benchmark.yaml`의 models 목록과 `config.json`의 available_models에 추가.
- ECAPA 엔진은 원본 `extract_speaker_ref.py`(git 등 다른 백업)에서 복원 필요.
