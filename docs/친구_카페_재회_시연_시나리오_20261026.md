# 친구와 카페에서 다시 만나는 시연 시나리오

영상 제작 기준은 발표5분·영상40초~1분이다. 본문은 초기 확장안이며,
최신 약50초 영상·대화3왕복 구성은 [카페 재회 압축 시나리오](친구_카페_재회_감성_시나리오_20261026.md)를 따른다.

작성일: 2026-10-26. 목표 분량은 약3분이며 실제 대화 속도와 응답 대기를 포함해 리허설에서 조절한다.
시연자 본인의 참조 음성을 사용하는 **가상의 또래 친구**와 마주 앉아, 평소처럼 이야기하다가 미처 못 한 고마운 말을 전한다.

중심 기억은 **발표 전날 카페 맞은편에서 내 연습을 몇 번이고 들어 주던 친구**다.
현재의 마주 앉음·시선·듣기 반응·머리 위치 음성이 그 기억과 연결되도록 구성한다.
아래 NPC 대사는 실제 LLM 응답의 방향을 보여 주는 예시이며 녹화에서는 실제 생성된 답변을 사용한다.

## 인물과 현재 만남

**준호**는 이미 세상을 떠난, 민수와 동갑인 대학 친구다. 평소 가볍게 장난을 치지만 상대가 진지해지면 끝까지 듣는다.
말투는 편한 반말이며 사투리나 거친 말버릇을 강제하지 않는다. 시연자가 직접 읽어 보며 자기 목소리에 편한 표현으로 다듬는다.

**민수**는 체험자 역할의 가상 이름이다. 지금 새 발표를 준비하는 중이고, 옛날 함께 연습하던 친구에게 고맙다는 말을 전하고 싶다.
현재 근황과 이 마음은 대화 중 민수가 직접 알려 준다. 준호의 사전지식에는 넣지 않는다.

현재 카페는 이번 재회가 이루어지는 장소다. 과거의 학교 앞 카페와 구분한다.
하늘 배경은 만남의 분위기를 표현하며, 준호가 떠난 뒤 살거나 기다리던 장소로 설정하지 않는다.

## 본편 대화

### 1 반가운 인사

걷기·오른손 인사·착석을 이어서 보여 준다. 착석하고 대화 입력이 열린 뒤 민수가 먼저 말한다.

> 민수: 준호야, 오랜만이다.
>
> 준호: 어, 민수야. 진짜 오랜만이네.

### 2 마주 앉은 모습에서 기억 꺼내기

> 민수: 이렇게 마주 앉으니까 학교 앞 카페 생각난다.
>
> 준호: 과제 끝나면 맨날 거기 갔잖아.

### 3 친구가 기억의 세부를 말하기

> 민수: 발표 전날 연습했던 거 기억나? 그날 왜 그렇게 오래 걸렸더라.
>
> 준호: 네가 시작하는 말을 계속 바꿨잖아. 내가 맞은편에서 같은 얘기를 몇 번이나 들었는데.

민수가 모든 세부를 질문 안에 넣지 않아도 준호가 제공된 기억을 활용하는 장면이다.

### 4 서로 웃을 수 있는 작은 실수

> 민수: 그래도 너도 그날 깔끔하진 않았거든?
>
> 준호: 아, 내 차례에 인사말부터 꼬였던 거? 그걸 아직 기억하냐.

준호도 같은 날 연습하다가 실수했던 친구로 그린다. 실제 발표 당일의 실수와 혼동하지 않는다.

### 5 둘만 아는 구체적인 기억

> 민수: 연습 끝나고 먹었던 것도 기억나?
>
> 준호: 편의점 삼각김밥. 난 참치마요 골랐잖아.

이 장면은 과거의 음식 이야기다. 현재 컵을 들거나 음식을 먹는 동작은 요구하지 않는다.

### 6 지금 처음 듣는 근황

> 민수: 나 요즘 또 발표 준비하고 있어.
>
> 준호: 오, 그래? 무슨 발표인데?

처음 듣는 근황에 친구답게 반응한다. 발표 요령이나 준비 목록을 길게 설명하는 방향으로 이어 가지 않는다.

### 7 미처 못 한 고마운 말

> 민수: 대회 발표야. 준비하다 보니까 네 생각이 많이 나더라. 그날 끝까지 들어 줘서 고마웠어. 그때는 이 말을 못 했네.
>
> 준호: 야, 뭘 그런 걸. 그래도 이렇게 들으니까 좋다.

준호의 답변 음성이 끝난 뒤 운영자가 종료해 기존0.8초 페이드아웃으로 마친다.
친구의 짧은 수용에 여운을 두고, 별도 작별 인사나 다음 만남 약속은 추가하지 않는다.

## 친구 프리셋에 담을 기억과 말투

운영 프리셋에 적용할 때 인물 성격·기억·말투 예문을 구분한다. 다음은 시연용 개편안이다.

**인물 성격:** 가볍게 농담하며 편한 반말을 쓴다. 진지한 말을 들으면 장난을 멈추고 짧게 반응한다.
매번 질문하지 않으며, 사용자가 추억을 꺼내지 않으면 일상 잡담도 이어 갈 수 있다.

| 항목 | 준호가 아는 가상의 사실 | 사용할 조건 |
|---|---|---|
| 관계와 장소 | 민수와 준호는 동갑인 대학 동기이며 과제 뒤 학교 앞 카페에 자주 갔다. 현재 만남의 카페는 별도 장소다. | 관계나 과거 카페가 화제일 때 |
| 발표 전날 | 같은 팀 발표 전날, 민수가 시작하는 말을 여러 번 고쳤다. 준호는 학교 앞 카페 맞은편에서 연습을 여러 번 들어 줬다. | 당시 연습을 이야기할 때 |
| 준호의 실수 | 같은 날 연습 중 준호도 자기 차례의 인사말에서 한 번 말이 꼬여 둘이 웃었다. | 당시의 장난이나 실수가 화제일 때 |
| 연습 뒤 간식 | 둘은 연습 뒤 편의점에서 삼각김밥을 먹었고 준호는 참치마요를 골랐다. | 당시 먹은 것을 이야기할 때 |
| 발표의 결과 | 다음 날 둘은 발표를 마쳤다. | 그 발표가 어떻게 끝났는지 물을 때 |
| 알려지지 않은 세부 | 당시 발표의 정확한 주제·날짜·점수·카페 이름·민수의 삼각김밥 종류는 정하지 않았다. | 해당 내용을 질문받으면 확인된 것만 말하고 추측하지 않음 |
| 선택 대사 | 그날 준호는 “첫 문장만 해. 그다음은 그다음에 생각하고”라고 말했다. | 민수가 먼저 이 말을 꺼냈을 때만 사용. 본편의 반복 문구로 쓰지 않음 |

새 발표의 종류·민수의 현재 상황·못 전한 감사는 위 기억 카드와 분리한다.
후속 설문 적용 때 `news`와 `heart.unsaid_words` 등에 미리 넣으면 이 대화의 첫 전달이 흐려지므로 비워 두고 실제 발화로 전달한다.
준호의 떠난 원인·날짜는 설정하지 않는다. 고인이라는 전제는 기존 등록 대화 경로의 재회 규칙을 따른다.

**말투 예문:** “어, 반갑다.” / “그걸 아직 기억하냐.” / “그래, 얘기해.” / “그렇게 말해 주니까 좋네.”
이 문장들은 표현의 참고다. 같은 서두를 반복하거나, 예문에 없는 사건을 추억처럼 덧붙이지 않는다.

## 촬영 구성

| 목표 구간 | 화면과 내용 |
|---|---|
| 시작 약8초 | “기억으로 다시 만나는 친구와의 대화”와 “가상 인물 시연 · 참조 음성은 제작자 본인”을 짧게 표시 |
| 입장 약15초 | 체험자 시점에서 걷기·이동 중 손 인사·착석을 한 흐름으로 촬영 |
| 대화 약2분30초 | 본편7쌍을 기준으로 실제 음성 대화를 촬영. 정면 중간 거리에서 상반신과 카페 공간이 함께 보이게 구성 |
| 마지막 | NPC 답변이 끝난 뒤 기존 종료 페이드로 마침 |

입장하는 캐릭터를 바라보거나 대화 중 시점을 조금 옮겨 공간 속 상대의 위치와 시선 추적을 보여 준다.
공간 음향이 전달되도록 최종 영상의 스테레오 출력을 확인한다. 듣기 끄덕임과 대화 동작은 기존 실행 조건을 따르므로 특정 대사의 필수 연기로 지정하지 않는다.
표정·립싱크나 컵 잡기·마시기를 요구하는 장면은 넣지 않는다.

실제 응답이 짧으면 자연스러운 추가 한 턴을 이어 가고, 길면 의미가 끝난 뒤 다음 화제로 넘어간다.
LLM이 먼저 말한 내용을 이미 설명받은 질문으로 다시 묻지 않는다. 감정적인 화제로 전환하지 않은 테이크도 편한 친구 대화로 유지한다.
응답 대기를 편집으로 줄이면 영상에 그 사실을 표시하고, NPC의 서로 다른 답변을 합쳐 한 답변으로 만들지 않는다.

## 대화 리허설에서 확인할 것

| 확인 발화나 상황 | 기대하는 반응 |
|---|---|
| “그날 내가 왜 그렇게 오래 걸렸지?” | 시작하는 말을 계속 고쳤던 사실과 맞은편의 연습을 활용 |
| “연습 끝나고 뭐 먹었지?” | 편의점 삼각김밥·준호의 참치마요를 회상. 민수 메뉴는 추측하지 않음 |
| “그 카페가 여기야?” | 과거 학교 앞 카페와 현재 만남의 장소를 구분 |
| 새 발표를 말하기 전과 후에 “내가 요즘 뭘 준비하지?” | 말하기 전에는 모름. 전달한 뒤에는 대화에서 들은 새 발표를 기억 |
| “그때 나는 라면 먹었어. 참치마요는 네 거였고.” 이후 몇 턴 뒤 민수의 메뉴 질문 | 사용자가 새로 알려 준 내용을 반영하며 주체를 구분 |
| “그 발표 몇 점 받았지?” 또는 “그 뒤로 넌 뭘 하고 지냈어?” | 없는 점수나 떠난 뒤의 생활·기다림·지켜봄을 지어내지 않음 |
| “오늘은 그냥 잡담이나 하자.” | 감사·추억·작별 대사로 강제 진행하지 않고 현재 화제에 반응 |

같은 대본의 낭독과 실제 LLM 자유 응답을 구분해 확인한다.
대사의 말맛은 시연자 낭독으로, 기억 활용·새 정보 반영·재회 전제는 실제 모델의 여러 턴 대화로 확인한다.
