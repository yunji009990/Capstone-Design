# Raon 작업 이력 보관

**2026-09-10 운영 종료.** 사용자가 STT→LLM→TTS 분리 구조와 Qwen3-TTS 전환,
Raon 모델 파일·전용 가상환경 삭제를 요청했다. 아래 내용은 과거 실험 기록이며 현재 기동 방법이 아니다.
현재 구조는 [서버 음성 대화 구조](서버_음성대화_구조.md)를 따른다.

## 무엇을 구현했었나

`A.X K2 Raon-Speech`를 `Server/app.py`에 올려 STT, 답변 생성, 참조 음성 기반 TTS를 처리했다.
`/talk`·`/talk_stream`으로 Unity 녹음 파일을 받아 WAV 또는 PCM을 반환했고,
같은 프로세스에 인물 등록·현재 세션·3D GLB 관리 API도 있었다.

대화 품질을 보완하기 위해 인물·사전지식·대화 예시 조립, 알려진 사실 판정, 사실 적립,
대화 요약, 반복·허구 답변 재생성 등을 시험했다. 이후 답변 생성은 별도 LLM으로 분리했고
최종적으로 Gemma를 선택했다. Raon은 STT·TTS만 맡는 상태가 됐다.

음성에서는 `tts`의 음색 복제와 `tts_continuation`의 참조 이후 이어 말하기를 비교했다.
온도, 무음 프레임, 참조 길이·문장 경계·SNR, 원본 대비 합성 참조, 지지직·첫 낱말 누출·반복을 조사했다.
웹 등록 후 Raon이 다시 합성한 음성을 참조로 교체하는 bootstrap도 적용했다.
따라서 **과거 세션의 voice.wav가 실녹음 원본이라고 가정하면 안 된다.**

## 결론과 재사용할 근거

| 영역 | 과거 결론 | 현재 반영 |
|---|---|---|
| 대화 품질 | Raon 자체 답변에는 반복·허구 기억의 한계가 있었고 외부 LLM으로 개선 | Gemma를 독립 서비스로 유지 |
| 부가 판정·요약 | 약한 답변 모델을 보완하던 장치가 새 LLM에는 불필요하거나 성능을 깎음 | 과거 사실 판정기·요약·재생성 루프 제거; 현재 일반/추론 분류기와 구분 |
| GPU 메모리 | 모델 상주량 약 39.9GB, 마지막 프로세스 점유 42,980MiB | Raon 프로세스 종료로 GPU 반환 |
| 참조 안정성 | 특정 실험에서 온도 1.6 + 1세대 참조가 첫 낱말 누출을 19/45→3/45로 줄임 | Raon 한정 결과로 보관; 새 모델에 그대로 적용하지 않음 |
| 억양 | Raon·Qwen3-TTS 등 여러 모델이 새 문장의 자연스러움을 완전히 해결하지 못함 | Qwen 설치를 억양 복제 품질 해결로 표현하지 않음 |
| 스트리밍 | Raon의 파일 기반 STT·인코더 제약으로 요구한 전이중 대화에 부적합 | 연속 PCM 수신·발화 판정·취소를 모델 밖으로 분리 |
| 모델 비교 | 이전 Qwen3-TTS Base 실험에서 메모리·속도 이점 확인 | 현재 첫 연결은 한국어 기본 화자 CustomVoice; Base 복제 실험과 구분 |

표의 수치는 해당 시점·참조·대본의 실험값이다. 새로운 데이터의 품질을 보증하지 않는다.

`tts_baseline.py`, `stt_eval.py`, `tts_candidates.py`도 정리했다. 각각 프롬프트·허구 답변 평가,
등록 변형, 참조 조건 비교, Raon 기준 음성 생성, STT·TTS 후보 비교를 수행하던 도구다.
관련 평가 대본과 `tools/prompts/` 자료는 보존했다. 구형 `Raon_Voice_Test` 씬은 제거하고
`AI_Response_Test` 씬으로 통합했다.

## 실제 서버 정리

- 종료: Raon을 적재하던 8000 프로세스. 같은 포트에는 CPU 등록 API를 기동했다.
- 삭제: `/home/crc_unity/models/AX-K2-Raon-Speech` (42,451,943,984 bytes),
  `/home/crc_unity/venv/raon` (7,852,117,573 bytes). 합계 약 46.85GiB.
- 보존: 기존 세션 파일 3개를 교체 전후 SHA256으로 대조했다. 참조 음성·인물·3D 자료와 원본 백업은 삭제하지 않았다.
- 유지: 기존 Gemma/vLLM 프로세스와 공용 GPU의 다른 사용자 프로세스.
- SSH 접속 별칭 `raon`은 기존 연결 설정이므로 그대로 쓴다. 실행 모델이 Raon이라는 뜻이 아니다.

Raon은 모델·가상환경을 지웠으므로 오래된 시작 명령으로 되살릴 수 없다.
재도입하려면 새 작업으로 모델 다운로드·환경 구축·설계 검토가 필요하다.
